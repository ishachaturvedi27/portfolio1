### Writing Classes 

Classes played a huge role in orginazation of our levels such as seperating game objects such as the player, enemies, platforms, and npcs. As each class has its own properties and features. 

Here are some places that it was used:

- our ocean adventure level 
- game levels
- to create new variables 


### Methods and Parameters 

We used methods and parameters to create functions that could be used in various places that controlled things such as actions,movement,collision,and the general mobility of the game. 
Here are some exmaples of how we used this:
- movement functions ( player, enemy, etc...)
- collisions methods detecion ( walls, enemies, etc...)
- action functions ( interactions, npcs, etc... )


### Instantiation & Objects
We used instantiation and objects to create  different elements of the game efficeintly. They provided features including player interactions, movement, using orginization creating classes from objects. 
- creating enemy objects 
- managing player actions ( movement )
- collectibles and obstacles

### Basic Inheritance
We used basic inheriance to organize multiple game elements by allowing classes to share various common feaures instead of repetition.

- the enemy and player using similar game object properties 
- collectibles and obstacles sharing properties. 

### Mehtod Overriding 
We used method overriding in muiltiple parts of our game. We used it to customize behabiors for different game objects still using parent classes mehtods though. 

- so enemies could move or kill the playyer on collision ( shark )
- collectibles dissapearing on collision with the player ( coins )

### Constructor Chaining 

We had used constructor chaning in order to efficiently put objects into action by passing shared properties through parent and child classes, to reduc repeating code.

- enemies could inherit shared properties such as position, speed and scale factor, etc..
- intilizing player objects through movement settings, collision, etc..
