### Writing Classes 

Classes played a huge role in the organization of our levels by separating game objects such as the player, enemies, platforms, and NPCs. Each class had its own properties and behaviors, which made the game easier to manage and develop.

Here are some places where classes were used:

- our ocean adventure level  
- game levels  
- creating new variables and objects  

<div class="code-runner">
<pre><code class="language-javascript">
// Example of a basic class
class Player {
    constructor(name, speed) {
        this.name = name;
        this.speed = speed;
    }

    move() {
        console.log(this.name + " is moving!");
    }
}

const player1 = new Player("Explorer", 5);
player1.move();
</code></pre>
</div>

### Methods and Parameters 

We used methods and parameters to create functions that controlled actions, movement, collision, and general mobility throughout the game. These methods could be reused in multiple parts of the project.

Here are some examples of how we used them:

- movement functions (player, enemy, etc...)  
- collision detection methods (walls, enemies, etc...)  
- action functions (interactions, NPCs, etc...)  

<div class="code-runner">
<pre><code class="language-javascript">
// Method with parameters
function movePlayer(direction, speed) {
    console.log("Moving " + direction + " at speed " + speed);
}

movePlayer("left", 10);
</code></pre>
</div>

### Instantiation & Objects

We used instantiation and objects to efficiently create different game elements. Objects helped with organization, player interactions, movement, collectibles, and obstacles.

Examples include:

- creating enemy objects  
- managing player movement  
- collectibles and obstacles  

<div class="code-runner">
<pre><code class="language-javascript">
// Object instantiation
class Enemy {
    constructor(type, health) {
        this.type = type;
        this.health = health;
    }
}

const shark = new Enemy("Shark", 100);

console.log(shark.type);
</code></pre>
</div>

### Basic Inheritance

We used inheritance to organize multiple game elements by allowing classes to share common features without repeating code.

Examples:

- enemy and player classes sharing game object properties  
- collectibles and obstacles sharing properties  

<div class="code-runner">
<pre><code class="language-javascript">
// Basic inheritance
class GameObject {
    constructor(x, y) {
        this.x = x;
        this.y = y;
    }
}

class Enemy extends GameObject {
    attack() {
        console.log("Enemy attacking!");
    }
}

const enemy1 = new Enemy(10, 20);
enemy1.attack();
</code></pre>
</div>

### Method Overriding 

We used method overriding in multiple parts of the game to customize behaviors for different game objects while still using parent class methods.

Examples:

- enemies damaging the player on collision  
- collectibles disappearing when touched  

<div class="code-runner">
<pre><code class="language-javascript">
// Method overriding
class Animal {
    speak() {
        console.log("Animal sound");
    }
}

class Shark extends Animal {
    speak() {
        console.log("Shark attack!");
    }
}

const sharkEnemy = new Shark();
sharkEnemy.speak();
</code></pre>
</div>

### Constructor Chaining 

We used constructor chaining to efficiently initialize objects by passing shared properties through parent and child classes. This reduced repeated code.

Examples:

- enemies inheriting position, speed, and scale  
- player objects using shared movement settings and collisions  

<div class="code-runner">
<pre><code class="language-javascript">
// Constructor chaining
class Character {
    constructor(name, speed) {
        this.name = name;
        this.speed = speed;
    }
}

class Player extends Character {
    constructor(name, speed, health) {
        super(name, speed);
        this.health = health;
    }
}

const hero = new Player("Diver", 8, 100);

console.log(hero.name);
</code></pre>
</div>
