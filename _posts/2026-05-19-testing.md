### Gameplay Testing

Gameplay testing helped us make sure Ocean Adventure was actually fun, balanced, and working correctly. We constantly tested the game while building it so we could find bugs and improve gameplay.

We used gameplay testing for:

- checking if sharks moved correctly  
- testing player movement and controls  
- making sure coins could be collected  
- balancing enemy speed and difficulty  
- checking collisions and score systems

// Gameplay testing example

let playerHealth = 100;

if (playerHealth <= 0) {
    console.log("Game Over");
} else {
    console.log("Player is still alive");
}
</code></pre>
</div>

### Integration Testing

Integration testing helped us make sure all the different parts of Ocean Adventure worked together correctly. Since the game had many systems like movement, collisions, enemies, and scoring, we needed to test if everything connected properly.

We used integration testing for:

- making sure collisions updated the score  
- checking if enemies interacted with players correctly  
- testing level loading with game objects  
- making sure NPCs, sharks, and coins all worked together  

<div class="code-runner">
<pre><code class="language-javascript">
// Integration testing example

function collectCoin(score) {
    score += 10;
    return score;
}

let updatedScore = collectCoin(20);

console.log(updatedScore);
</code></pre>
</div>

### API Error Handling

API error handling helped us prevent crashes when outside systems or data failed to load correctly. This made the game more stable and prevented unexpected problems.

We used API error handling for:

- leaderboard systems  
- loading outside data  
- handling failed requests  
- preventing game crashes  

<div class="code-runner">
<pre><code class="language-javascript">
// API error handling example

fetch("https://example.com/leaderboard")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.log("Error loading leaderboard");
    });
</code></pre>
</div>

### Testing & Verification

Testing and verification helped us make sure everything in Ocean Adventure was actually working the way it should. We didn’t just assume things worked, we tested them over and over again while building the game. This helped us catch small bugs early before they became bigger problems later.

We used testing and verification for:

- checking if game features worked correctly  
- making sure player movement and controls responded properly  
- testing collisions between sharks, coins, and the player  
- verifying that score updates were accurate  
- making sure the game didn’t break after new updates  

<div class="code-runner">
<pre><code class="language-javascript">
// Testing and verification example

let score = 0;
score += 10;

if (score === 10) {
    console.log("Testing works correctly!");
}
</code></pre>
</div>

### Summary

Testing and error handling were really important while building Ocean Adventure. Gameplay testing helped improve the player experience, integration testing made sure all the systems worked together, API error handling helped prevent crashes and broken features, and testing & verification helped us confirm everything was working correctly.
